# Game display artwork

Original artwork generated for **Steal an OP Item**. The art depicts the game's contested collectible conveyor, overhead item carrying, protective bases, and legendary relics.

- `StealAnOPItem_Thumbnail_1920x1080.jpg`: standard 16:9 experience thumbnail, 1920 × 1080 pixels.
- `StealAnOPItem_Icon_512.png`: square experience icon, 512 × 512 pixels.
- `StealAnOPItem_Thumbnail.png` and `StealAnOPItem_Icon.png`: original full-resolution generated artwork.

Upload the thumbnail and icon through the experience's Creator Dashboard artwork settings. These files are separate from the place and are not automatically published by opening the game in Studio.

The images are promotional illustrations, not captures of a live Studio playtest.
