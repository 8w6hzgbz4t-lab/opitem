START WITH THE MUSIC

1. Upload relic-rivalry-loop.ogg at Creator Dashboard > Creations > Development Items > Audio > Upload Asset.
2. Use the account or group that owns Steal An OP Item.
3. Name: Relic Rivalry - Original Battle Loop
   Description: Original synth battle loop for Steal An OP Item.
4. Wait for approval. Open the audio asset's Permissions > Experiences and allow your experience if required. Use its universe ID when asked for an experience ID.
5. Copy the numeric audio asset ID. Send it back as: Music: YOUR_AUDIO_ID

The ten WAV sound effects are optional. Upload them later and fill in AudioIDs.csv or send cue/ID pairs. Built-in SFX are already configured as fallbacks.

Music stays silent until its uploaded ID is added to AudioConfig. Existing Developer Product IDs stay the same when updating the same experience. Audio setup does not enable checkout.

See AUDIO_UPLOAD.md in the release download for full instructions and playback checks.
