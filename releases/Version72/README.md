# Version 72 — Crossover Art

Open `releases/StealAnOPItem_72_CrossoverArt.rbxlx` in Roblox Studio and press **Play**. The map is generated by the game's existing server scripts. This release extends the complete Version 71 game, which preserves the user's uploaded Version 69 place and its backups.

## Recognizable crossover collectibles

| New buyable item | Rarity | Price | Base income / second | Approximate chance per spawn |
| --- | --- | ---: | ---: | ---: |
| Transformers AllSpark | Mythic | $280,000 | $2,600 | 0.1363% |
| Transformers Matrix of Leadership | Legendary | $72,000 | $780 | 0.2310% |
| Optimus Prime Energon Axe | Epic | $19,000 | $255 | 0.4511% |

The AllSpark has six sculpted metal faces and 36 angular glyphs. The Matrix has two open handles and a faceted blue energy crystal. The Energon Axe has a tapered orange crescent edge and a detailed red/blue mechanical emitter. All are native Roblox models, requiring no Meshy subscription, paid service, imported texture or external model asset ID.

The catalog now has **69 items**. All 66 previous item definitions, names, prices, income, abilities, weights, model geometry and SurfaceGui properties remain identical to Version 71. This includes the Millennium Puzzle, improved Gary shell, Krabby Patty and Secret Formula. The eight-power system, collection rewards and transaction rules are preserved.

The conveyor continues to select rarity first, then an item inside that rarity. The new axe receives the existing reduced axe weight. Adding items does not change overall rarity frequencies; it shares the selected rarity's probability among its items. Exact probabilities are in `spawn-rates.json` and `spawn-rates.csv`.

## A shared relic-gallery setting

The art direction takes inspiration from **Magic: The Gathering — Universes Beyond**: recognizable objects from different worlds presented together with a consistent setting. Existing fantasy, technological and animated-world collectibles retain their own silhouettes and colors.

All eight bases now have dark stone display frames, numbered plinths, bronze floor inlays, embossed wall panels and discreet entrance plaques. Matching stone promenades, six shallow relic medallions, a finished Power Lab surround and portal arrival trim connect the shared areas.

The presentation adds 936 base parts and 237 shared-area parts. All new trim is noninteractive. Original solid roofs, walls, perimeter barriers and item-only disposal retain their collision settings. Base ownership labels, workstations, spawn points, eight storage slots, green entrance/protection lines and display clearances are preserved. Existing roof camera fading still applies; no new overhead slab was added.

## Reproduce the checks

From the repository root, with Python 3, Pillow, NumPy, Matplotlib, `texlua` and the official Luau CLI:

```sh
python tools/build_v72_place.py releases/StealAnOPItem_71_SecretFormulaAndRa.rbxlx
python tools/run_game_checks.py --root roblox/v72-game --baseline roblox/v71-game --check tests/v72_catalog.lua --luau /path/to/luau
python tools/audit_v72_items.py --skip-preview --luau /path/to/luau
texlua tests/v72_presentation.lua
python tools/package_v72_release.py
```

Editable sources are in `roblox/v72-game/`. `roblox/v72-pre-polish/` is the immutable world-test baseline before the additive base and plaza finishes. The complete handoff is `releases/Version72_SourceAndGame.zip` and the branch is `codex/version-63-handoff`. The default branch is unchanged.
