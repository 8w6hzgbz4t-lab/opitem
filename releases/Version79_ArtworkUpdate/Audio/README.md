# Audio for your current V79 game

Start with relic-rivalry-loop.ogg. Upload it through Creator Dashboard under the account/group that owns your game, grant the game permission and wait for approval. Then edit Music.AssetId in ServerScriptService → OPItemV2 → AudioConfig in your current V79 file while Play is stopped.

The ten WAV effects are optional replacements for working built-in sounds. Their mapping is in ../STORE_AND_AUDIO_SETUP.md. No upload IDs are configured automatically.
