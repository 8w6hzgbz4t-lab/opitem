# Steal An OP Item

- Complete source, game, audio and art: `releases/Version76_SourceAndGame.zip`.

Version 76 adds a developer-only fourth Royal Seal slot, triple-jump flight with fixed upright orientation, a prepared cash shop bench, audio feedback and display artwork. Paid items lost after pickup return to their conveyor pickup point without refunding the buyer; unfinished and losing bids still refund. Every successful offensive power can dislodge a carrier after shield/immunity checks. Static Slifer construction is retired; the animated dragon stays. All 76 collectibles, their stats/models, the Millennium Puzzle, Ra and other scenery are preserved.

Developer tools belong only to `Goverment_cheesee`; they are never sold. The cash shop is a disabled preview of proportional game-cash packs. Real purchases require persistent profiles and atomic receipt grants before future activation. Background music requires the owner's Roblox audio upload ID; built-in sound effects work immediately. This remains a session alpha with no saved progress.

The models use native Roblox geometry and require no Meshy subscription, API key or external model asset IDs. The eight-power system and Infinity Stone rewards already present in Version 69 are preserved.

Open the `.rbxlx` in Roblox Studio and press Play. Offline geometry, catalog, transaction, animation, full-world and preservation checks pass. Live Studio visual/performance and multiplayer checks remain required. Nothing has been published to Roblox. Main is unchanged; handoffs are on `codex/version-63-handoff`.

Earlier releases remain available in `releases/`. The original Version 69 upload is preserved in `roblox/original/`, and the editable Version 76 sources are in `roblox/v76-game/`. The old `meshy/` folder is an optional API workflow and is not required.
